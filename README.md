# ⏱️ 교실 TV용 활동 타이머 (Classroom Activity Timer)

수업 활동 시간에 교실 TV 및 전자칠판에 띄워두고 편리하게 사용할 수 있는 고대비 타이머 웹앱입니다.

## ✨ 주요 기능
- **초대형 디스플레이**: 교실 맨 뒤에서도 한눈에 보이는 가변형 대형 폰트
- **시간 프리셋 & 직접 입력**: 5분, 10분, 15분 원클릭 버튼 및 분 단위 직접 설정
- **1분 이하 시각 경고**: 남은 시간이 1분(60초) 이하가 되면 선명한 호박색(Amber)으로 색상 전환
- **종료 효과**: 화면 전체 점멸 효과 + 종료 안내 배너 + Web Audio API 기반 청아한 학교 종소리(차임벨)
- **교사용 편의 기능**: 활동 제목 직접 수정(클릭하여 편집), +1분/-1분 빠른 조절, 전체화면(F11) 전환, 키보드 단축키 지원(Space: 시작/일시정지, R: 초기화, F: 전체화면)

## 💻 실행 방법
별도의 설치나 빌드 과정 없이 `index.html` 파일을 더블클릭하거나 브라우저로 열면 즉시 실행됩니다.
